## 🎯 Alineación con el Examen Google Cloud Associate Cloud Engineer (ACE v4.0)

Este curso cubre habilidades prácticas y operativas de alta ponderación para el examen ACE:
1. **Dominio 1 (Entorno de Nube):** Configuración de IAM, permisos mínimos y observabilidad con Cloud Monitoring.
2. **Dominio 2 (Planificación e Implementación):** Creación de buckets en Cloud Storage mediante consola y CLI `gcloud storage`, despliegue de Cloud Run functions e infraestructura de colas Pub/Sub.
3. **Dominio 3 (Operación Exitosa):** Monitoreo de VMs con métricas del Ops Agent, publicación y suscripción de mensajes y resolución de problemas.
4. **Dominio 4 (Acceso y Seguridad):** Gestión granular de roles IAM, cuentas de servicio y aislamiento de permisos de almacenamiento.
